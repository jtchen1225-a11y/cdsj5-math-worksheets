# 澳門四校聯考 · 100 分鐘專題限時練習工作紙（課堂互動講評系統）

> 🔒 **聖若瑟教區中學第五校 · 高三數學科組校內專用教學資產**

---

## 📌 系統簡介

本系統為專為澳門四高校聯合入學考試（JAE）高三第二輪專題衝刺設計的「100 分鐘限時練習工作紙」數位化互動講評平台。涵蓋全八大黃金專題、共 80 道高品質原創梯級試題，完整支援課堂投影、分步探究與各格式講義下載。

### 🌟 核心功能特色
1. **全八大黃金專題完整覆蓋**：
   - Topic 01: 解析幾何與圓錐曲線（切線長幾何探究、點差法中點弦）
   - Topic 02: 微積分極值與定積分應用（導數幾何意義、切線斜率探究、單調性與極值）
   - Topic 03: 複數代數與複平面幾何（阿根圖共軛實軸對稱、棣美弗定理、單位根幾何）
   - Topic 04: 矩陣線性方程組與數學歸納法（二階旋轉矩陣變換、高斯消元、逆矩陣）
   - Topic 05: 立體幾何與空間向量建系（空間直角坐標系投影、法向量、線面角/二面角）
   - Topic 06: 三角函數解三角形與平面幾何（正餘弦定理、外接圓直徑不變性、面積最值）
   - Topic 07: 數列求和與代數不等式（等差等比散點趨勢、錯位相減、裂項相消、柯西不等式）
   - Topic 08: 計數原理二項式定理與概率統計（二項式展開楊輝三角直方圖、超幾何分佈）
2. **階梯式三部曲解題揭曉**：
   - 階段一：破題思維方向（Thinking & Strategy）
   - 階段二：關鍵突破口與公式定理（Key Hints & Formulas）
   - 階段三：嚴格對標聯考評分標準之踩點規範步驟（M 方法分、A 答案分、B 獨立分）
3. **原生 SVG 向量互動探究**：
   - 純原生 JavaScript + SVG 渲染，零依賴、秒加載。
   - 支援拖曳滑桿動態觀察幾何圖形變化與代數規律。
4. **雙版本 Word / 向量 PDF 下載通道**：
   - 學生實戰版（含題目與作答留白方框，適合限時印發練習）
   - 教師培優版（含完整詳解、干擾項陷阱剖析與分步給分細則）
5. **課堂教學輔助教具**：
   - 教師課堂進度控制（可鎖定/解鎖指定題目，防止學生提前查看答案）
   - 題目全螢幕滿版放大至黑板講解
   - MathJax 3 向量數學公式渲染

## 📂 檔案目錄結構

- `index.html`：校內專用講評系統總入口目錄（含 8 大專題導覽與全套檔案下載按鈕）
- `worksheet01.html` ~ `worksheet08.html`：各專題獨立互動講評頁面
- `ch-ws-topic01.js` ~ `ch-ws-topic08.js`：各專題 10 題原創題庫數據、解析與 SVG 探究參數
- `engine.js`：互動簡報引擎、快捷鍵監聽、滿版放大、課堂進度鎖定與 QR Code 生成
- `style.css`：黑夜高對比課堂投影樣式表
- `svg.js`：SVG 向量幾何繪圖輔助模組
- `qrcode.min.js`：課堂即時二維碼生成庫
- `downloads/`：全套 34 份學生版/教師版 Word (.docx) 與無損向量級 PDF (.pdf) 下載包

## 💻 快速使用說明

- 本系統為純靜態前端架構，無需任何後端伺服器或資料庫。
- 直接以瀏覽器開啟 `index.html` 即可完整離線運行，或透過本校專屬線上部署網址於教室電子白板/投影機直接使用。
